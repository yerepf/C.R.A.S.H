# Configuración de claves/API tokens

Antes de iniciar el proyecto, crea un archivo `.env` (o usa tu sistema de entorno) con el siguiente contenido (ver .env.example):

VITE_MAPBOX_TOKEN=tu_token_mapbox_aqui
VITE_OPENROUTER_API_KEY=tu_token_openrouter_aqui

**Importante:** NUNCA publiques estos tokens, solo usa `.env.example` en el repositorio público.
